# DSOOP Quiz Prep

Interactive study site for Data Structures & OOP (Java), built with Next.js.

```bash
npm install
npm run dev     # http://localhost:3000
```

- **9 lessons** with step-through visualizers (code stepper, memory diagrams, linked lists, arrays, growth charts)
- **Code Lab**: build solutions from shuffled lines (with decoys), 14 problems
- **Quiz Lab**: 70 questions, Exam / Learn modes, per-topic review
- **Cheat sheet** for quiz morning

Progress is stored in your browser's localStorage only.
Content lives in `components/lessons/`, `lib/questions.ts` and `lib/parsons.ts`.
